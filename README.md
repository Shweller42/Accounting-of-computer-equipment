# 🖥️ Система учета компьютерной техники

Десктопное приложение для автоматизации учета, контроля состояния и ведения журнала обслуживания компьютерного оборудования организации. Разработано в рамках курсового проекта.

## 🛠 Технологический стек
* **Язык программирования:** C#
* **Платформа:** .NET 10.0
* **Интерфейс:** WPF (Windows Presentation Foundation)
* **База данных:** SQLite (локальная встраиваемая СУБД)

## 🚀 Основные возможности
* **Учет техники:** Удобный реестр (добавление, редактирование, удаление) компьютеров, ноутбуков, серверов и сетевого оборудования.
* **Журнал обслуживания:** Фиксация истории ремонтов, замен комплектующих и стоимости работ с привязкой к конкретной технике.
* **Целостность данных:** Реализовано каскадное удаление — при удалении устройства автоматически очищается история его ремонтов.
* **Поиск и фильтрация:** Быстрый поиск по модели или инвентарному номеру, а также фильтрация по кабинетам и техническому состоянию.
* **Аналитика и статистика:** Просмотр общих показателей парка техники и подсчет затрат на ремонт за выбранный год.
* **Экспорт отчетов:** Выгрузка отфильтрованных данных в формат **CSV** для последующего анализа в Microsoft Excel.

## 📊 Производительность и надежность
* Загрузка списка оборудования из базы данных занимает менее 2 секунд.
* Поиск и фильтрация выполняются менее чем за 0.5 секунды.
* Использование транзакций SQLite защищает базу данных от повреждения при аварийном завершении программы.
